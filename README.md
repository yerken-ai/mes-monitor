# Бот скриншотов линии Алматы (MES tn-mes2.aspect-systems.ru) → Telegram

Бот работает по запросу:
- **Никакого спама и лишних уведомлений**: бот молчит, пока вы к нему не обратитесь.
- Вы отправляете команду **/status** (или нажимаете кнопку **«📸 Статус линии»**).
- Бот переходит на детальный экран мониторинга линии завода **«Алматы»**, делает скриншот и присылает свежее фото с датой и временем.

---

## 1. Готовые секреты для GitHub
Все данные уже сгенерированы и сохранены в файле `СЕКРЕТЫ_ДЛЯ_GITHUB.txt`:
1. `TG_BOT_TOKEN` — токен вашего Telegram-бота.
2. `TG_CHAT_ID` — ваш Telegram ID.
3. `AUTH_STATE_JSON` — куки активной сессии MES (сохранены из браузера).

---

## 2. Загрузка в GitHub репозиторий
1. Создайте на GitHub новый **Private (приватный)** репозиторий (например, `mes-almaty-bot`).
2. Загрузите туда файлы из этой папки:
   - `monitor.py`
   - `requirements.txt`
   - `.github/workflows/monitor.yml`
   - `.gitignore`
3. В настройках вашего репозитория на GitHub перейдите в:
   **Settings → Secrets and variables → Actions → New repository secret**  
   и добавьте 3 секрета из файла `СЕКРЕТЫ_ДЛЯ_GITHUB.txt`.

---

## 3. Запуск и использование
1. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
2. Слева выберите workflow **MES Almaty Telegram Bot** и нажмите **Run workflow** (режим по умолчанию `bot`).
3. Откройте вашего бота в Telegram и отправьте команду `/start` или `/status`.
4. Бот пришлет ответное фото экрана линии! В чате также появится кнопка **«📸 Статус линии»** для быстрого запроса фото в один клик.
